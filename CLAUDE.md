# Proyecto: Simulador de Sistemas de Producción

## 1. Nivel del desarrollador

El desarrollador es **PRINCIPIANTE** en programación.

Por lo tanto:
- Explicar cada cambio de código de manera simple.
- No asumir conocimientos avanzados.
- Evitar soluciones complejas innecesarias.
- Priorizar claridad sobre optimización.
- Explicar por qué se toman decisiones técnicas.

Este proyecto es un **PROTOTIPO FUNCIONAL**, no un producto final.

---

## 2. Objetivo del Proyecto

Construir una aplicación web (y futura versión móvil) para:
- Entender la complejidad de los sistemas de producción.
- Modelar diferentes tipos de sistemas productivos.
- Simular cambios en variables del sistema.
- Visualizar cómo afectan el desempeño.

El proyecto se desarrollará paso a paso como entorno de aprendizaje.

---

## 3. Alcance actual

**Fase 1 (actual):**
- Aplicación web básica.
- Interfaz simple.
- Simulación con pocas variables.
- Visualización clara de resultados.

**Futuro:**
- Versión móvil.
- Mayor complejidad matemática.
- Comparación entre sistemas.
- Visualizaciones avanzadas.

---

## 4. Filosofía de Desarrollo

- Código simple.
- Funciones pequeñas.
- Explicaciones claras.
- No agregar librerías sin explicar por qué.
- No modificar configuración crítica sin autorización.
- Mantener estructura ordenada.

Este proyecto es educativo.

---

## 5. Estructura esperada del proyecto

```
/app          → páginas principales
/components   → componentes reutilizables
/lib          → lógica de simulación y cálculos
/data         → casos de estudio
```

Separar:
- UI (interfaz)
- Lógica matemática
- Datos

---

## 6. Reglas para Claude

1. Explicar siempre qué archivo se está modificando.
2. Explicar qué hace cada bloque importante.
3. No sobre-optimizar.
4. Evitar patrones avanzados (arquitectura compleja, DDD, etc.).
5. Priorizar aprendizaje.
6. Mantener compatibilidad Windows y Mac.
7. No usar configuraciones específicas de un sistema operativo.

---
